## Descrição

Project-kat é um jogo desenvolvido com a javascript, 
tendo como base o uso da tag canvas que permite fazer animações por uma api 
de javascript, permitindo manipular esse elemnto atraves de um contexto, os 
scripts são separados por responsabilidade no codigo, assim cada uma tendo uma função.
Esta versão é apenas uma demo onde ele ainda continua voltado a um roguelike, mas atualmente esta sendo desenvolvido 
em godot para uma versão voltada a rpg/survivel.

O objetivo central desse projeto era inicialmente um projeto de faculdade com prazo de duas semanas de desenvolvimento, onde tinha como principal mecanica
a progressão por tempo sendo o objetivo do jogador se manter o maixmo de tempo vivo possivel, porem em sua versão de godot a unica mecanica que 
vai se manter e a geração de mapa prose dural, que esta sendo aprimorada no seu atual desenvolvimento.
